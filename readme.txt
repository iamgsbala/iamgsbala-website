A single-page personal website for Balamurugan G., based on the supplied professional expertise profile.

INSTALLATION
Upload iamgsbala-1.1.0.zip in Appearance > Themes > Add New > Upload Theme and activate it.
The homepage uses front-page.php automatically; no page builder or companion plugin is required.
Appearance > Customize > Site Identity: upload your custom logo and site icon.
Appearance > Customize > iamgsbala Profile: change name, headline, introduction, contact email, booking URL and LinkedIn URL.
Install/activate Contact Form 7, create the enquiry form from docs/contact-form.txt, configure its Mail tab using docs/contact-setup.md, then select it in Customize > iamgsbala Profile > Contact Form 7 form. Contact forms live in the WordPress database and do not travel inside a theme ZIP.
Set product landing-page URLs in the same Customizer section after publishing the subdomains. Empty URL settings link to the published WordPress.org listings.
Set your site title to iamgsbala and a suitable tagline in Settings > General.

CONTENT
Service/process copy lives in front-page.php; products and contact/FAQ sections live in template-parts/. Edit those templates for deeper changes.
The profile document supports the 11+ years claim. No client logos, testimonials, revenue statistics or unsupported case studies have been added.
FileOps Monitor and StoreOps Auditor for WooCommerce are featured. Example reports are styled illustrations, not live scan data.
Contact Form 7 integration is optional; when unavailable, configured email/contact links remain usable. No analytics, external fonts, payment flow or Pro checkout is included.
The theme does not modify plugins, user content, site URLs or contact information on activation.

BEFORE PUBLIC LAUNCH
The owner's supplied GS logo is bundled as a fallback; Site Identity can override it. Set approved public contact details, configure the selected contact form and verify actual email delivery on production.
Review the copy, verify current facts, and deploy to iamgsbala.com with HTTPS, backups and normal WordPress migration checks.
Full sections are currently template-editable; this is not a block-site editing theme.
